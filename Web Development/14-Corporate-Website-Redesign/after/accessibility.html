Accessibility statement

We want as many people as possible to be able to use this website.

What you can do on this website

  • Zoom in up to 400% without the text spilling off the screen
  • Use the whole site with just a keyboard
  • Use the site with a screen reader, such as NVDA, JAWS or VoiceOver
  • Read the text easily: we use a typeface designed for low-vision readers and plain English
  • Turn off animations by turning on "reduce motion" in your device settings

How accessible this website is

This website was redesigned in October 2026 to meet the Web Content Accessibility Guidelines (WCAG) version 2.2, level AA. It was tested with automated checks (axe-core), keyboard-only use and zoom.

Known issues

  • Some older course leaflets are PDFs that may not work well with screen readers. Ask us for an accessible version.

Getting information in another format

If you need information in a different format, such as large print, easy read, audio or Braille, contact us:

  • Email hello@fernhill-college.example
  • Call 0113 496 0420

We will reply within 5 working days.

Reporting a problem

If you find a problem with this website, please tell us. It helps us improve it for everyone.
