API ENDPOINTS AND REQUEST DATA - Course Enrollment System
==========================================================
Base URL : http://localhost:8080
Format   : JSON (add header  Content-Type: application/json  on POST / PUT with a body)
Auth     : HTTP Basic on every /api/** URL (Postman: Authorization -> Basic Auth)

LOGINS
  admin                    / admin123      role ADMIN
  employee1 .. employee4   / employee123   role EMPLOYEE

WHO MAY CALL WHAT
  /api/courses                 any logged-in user (ADMIN or EMPLOYEE)
  /api/enrollments/**          EMPLOYEE only
  /api/admin/**                ADMIN only
  /  /index.html  /style.css  /app.js     no login (the web page itself)

NO LOGIN / LOGOUT ENDPOINT
  Basic auth is sent with every request, so there is no /login or /logout URL.
  A wrong or missing login returns 401.


======================================================================
1. BROWSE COURSES                                       (ADMIN or EMPLOYEE)
======================================================================
GET  http://localhost:8080/api/courses

Body   : none
Returns: only ACTIVE courses.

Response 200:
[
  {
    "id": 1,
    "title": "Java Basics",
    "description": "Intro to Java",
    "category": "Programming",
    "capacity": 2,
    "active": true,
    "approvedCount": 2
  }
]


======================================================================
2. SUBMIT AN ENROLLMENT REQUEST                         (EMPLOYEE only)
======================================================================
POST http://localhost:8080/api/enrollments

Body (JSON):
{
  "courseId": 6
}

Field     Type   Required   Meaning
courseId  number yes        id of the course to enrol in

The employee is NOT sent in the body; it is taken from the login.

Response 201:
{
  "id": 7,
  "courseId": 6,
  "courseTitle": "SQL Fundamentals",
  "employeeUsername": "employee1",
  "employeeName": "Employee One",
  "status": "PENDING",
  "requestedAt": "2026-10-15T15:30:12.456"
}

Errors:
  400  "courseId: courseId is required"      body is {}
  400  "Course '...' is not active"          course is inactive
  404  "Course not found with id 999"        unknown course
  409  "You have already requested this course"
  409  "Course '...' is full"                APPROVED count has reached capacity
  403                                         logged in as ADMIN


======================================================================
3. VIEW MY ENROLLMENTS                                  (EMPLOYEE only)
======================================================================
GET  http://localhost:8080/api/enrollments/my

Body   : none
Returns: only the logged-in employee's own requests, all statuses.

Response 200:
[
  {
    "id": 1,
    "courseId": 1,
    "courseTitle": "Java Basics",
    "employeeUsername": "employee1",
    "employeeName": "Employee One",
    "status": "APPROVED",
    "requestedAt": "2026-10-15T14:46:47"
  }
]


======================================================================
4. LIST ALL COURSES                                     (ADMIN only)
======================================================================
GET  http://localhost:8080/api/admin/courses

Body   : none
Returns: active AND inactive courses (same fields as endpoint 1).


======================================================================
5. CREATE A COURSE                                      (ADMIN only)
======================================================================
POST http://localhost:8080/api/admin/courses

Body (JSON):
{
  "title": "Docker Basics",
  "description": "Containers",
  "category": "DevOps",
  "capacity": 5
}

Field        Type     Required  Rule
title        text     yes       must not be blank
description  text     no
category     text     no
capacity     number   yes       at least 1
active       true/false  no     leave out = true (course is active)

To create an INACTIVE course, add:   "active": false

Response 201: the created course (same fields as endpoint 1, approvedCount 0).

Errors:
  400  "title: Title is required; capacity: Capacity must be at least 1"
       (send {"title":"","capacity":0} to see it)
  400  "Request body is missing or not valid JSON"     broken JSON
  403  logged in as EMPLOYEE


======================================================================
6. UPDATE A COURSE                                      (ADMIN only)
======================================================================
PUT  http://localhost:8080/api/admin/courses/{id}
     example: http://localhost:8080/api/admin/courses/2

Body (JSON) - same fields and rules as endpoint 5:
{
  "title": "Spring Boot",
  "description": "REST APIs with Spring",
  "category": "Programming",
  "capacity": 3,
  "active": true
}

Notes:
  - All of title / description / category / capacity are replaced, so send all of them.
  - "active" is optional: leave it out to keep the current value.
  - Send "active": false to deactivate, "active": true to reactivate.

Response 200: the updated course.

Errors:
  400  validation message (as in endpoint 5)
  404  "Course not found with id 999"


======================================================================
7. DELETE A COURSE                                      (ADMIN only)
======================================================================
DELETE http://localhost:8080/api/admin/courses/{id}
       example: http://localhost:8080/api/admin/courses/2

Body: none

Response 200 (plain text, not JSON):
  "Course deleted"                      course had no enrollments
  "Course has enrollments, so it was deactivated instead of deleted"

Errors:
  404  "Course not found with id 999"


======================================================================
8. LIST ENROLLMENT REQUESTS                             (ADMIN only)
======================================================================
GET  http://localhost:8080/api/admin/enrollments
GET  http://localhost:8080/api/admin/enrollments?status=PENDING

Body: none

Optional query parameter  status  = PENDING | APPROVED | REJECTED  (UPPERCASE)
Leave it out to get every request.

Response 200: list of enrollments (same fields as endpoint 3).

Errors:
  400  "Invalid value 'XYZ' for parameter 'status'"


======================================================================
9. APPROVE A REQUEST                                    (ADMIN only)
======================================================================
PUT  http://localhost:8080/api/admin/enrollments/{id}/approve
     example: http://localhost:8080/api/admin/enrollments/5/approve

Body: none   (the id in the URL is the ENROLLMENT id, not the course id)

Response 200: the enrollment with  "status": "APPROVED"

Errors:
  404  "Enrollment not found with id 999"
  409  "Enrollment is already APPROVED and cannot be changed"   (or REJECTED)
  409  "Course '...' is full"
  400  "Course '...' is not active"


======================================================================
10. REJECT A REQUEST                                    (ADMIN only)
======================================================================
PUT  http://localhost:8080/api/admin/enrollments/{id}/reject
     example: http://localhost:8080/api/admin/enrollments/6/reject

Body: none

Response 200: the enrollment with  "status": "REJECTED"

Errors:
  404  "Enrollment not found with id 999"
  409  "Enrollment is already APPROVED and cannot be changed"   (or REJECTED)


======================================================================
ERROR RESPONSE SHAPE (every error above)
======================================================================
{
  "status": 409,
  "error": "Conflict",
  "message": "Course 'Java Basics' is full",
  "timestamp": "2026-10-15T15:20:41.123"
}

401 (not logged in / wrong password) and 403 (wrong role) come from Spring Security
and have no JSON body.


======================================================================
STATUS CODE SUMMARY
======================================================================
200 OK            read, update, approve, reject, delete
201 Created       course created, enrollment requested
400 Bad Request   validation failed, malformed JSON, bad parameter, inactive course
401 Unauthorized  missing or wrong login
403 Forbidden     logged in, but the role is not allowed
404 Not Found     course or enrollment id does not exist
409 Conflict      duplicate request, course full, request already decided
